# 🍎 Big Apple — американский английский в Нью-Йорке

Уютная 3D-игра для изучения **американского английского** с нуля (A1 → A2).
Ты прилетаешь в Нью-Йорк, почти не зная языка, и строишь жизнь: снимаешь комнату,
заказываешь кофе, находишь работу и друзей. Каждый разговор — урок, а ошибки
игра объясняет по-русски.

Графика — low-poly в стиле Untitled Goose Game с «шейдерпаком», как в Minecraft:
мягкие тени (ambient occlusion), тени облаков, лучи солнца, свечение огней ночью,
мокрый асфальт в дождь, качающаяся листва и эффект миниатюры (tilt-shift).

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173 (откроется и с телефона в той же Wi-Fi сети)
npm run build      # готовая сборка в папке dist/ — её можно выложить на любой хостинг
```

Голос (микрофон) лучше всего работает в Chrome. Озвучка — встроенная в браузер (американский голос).

## Что есть в игре

| | |
|---|---|
| 🗽 **2 района** | Бруклин (улица с браунстоунами, парк) и Манхэттен (небоскрёбы, неон, площадь как Таймс-сквер). Между ними — метро |
| 📖 **2 главы, 11 заданий** | Знакомство, кафе, аренда жилья, еда, дорога, музыка (A1) → пицца, туристы, -ing, прошедшее время, собеседование (A2) |
| ✍️ **6 типов упражнений** | выбор ответа, сборка фразы из слов, письменный ответ, ответ голосом, аудирование, оплата |
| 🤔 **Объяснение ошибок** | что не так, почему, как правильно — на русском; персонаж переспрашивает «Sorry, what?» |
| 📝 **Дневник ошибок** | игра запоминает слабые темы и даёт их повторить |
| 📖 **Словарь** | интервальное повторение (система Лейтнера); слова добавляются нажатием в диалогах |
| 👂 **Подслушанные фразы** | прохожие говорят живые американские фразы — нажми, чтобы перевести и сохранить |
| 🏷️ **Подписи предметов** | подходишь к гидранту, такси, люку — видишь английское слово (и британский вариант) |
| 🍎 **16 золотых яблок** | спрятаны по городу, каждое — сленговое слово |
| 🌅 **Время суток и погода** | рассвет, день, закат, ночь, дождь; у персонажей расписание; ночной музыкант в парке |
| 🤖 **ИИ-собеседники** | свободный разговор с любым жителем через **Claude Haiku 5.5** с исправлением ошибок |
| 📱 **Телефон героя** | переписка с другом, словарь, ошибки, шпаргалка, задание дня, магазин, смена, настройки |
| ☕ **Мини-игра** | смена бариста: слушай заказы и готовь напитки на скорость |
| 🏠 **Своя квартира** | покупай мебель на заработанные деньги; спи, чтобы наступило утро |

### ИИ-разговоры (Claude Haiku 5.5)

В игре: **Телефон → Настройки → API-ключ**. Ключ берётся на
[console.anthropic.com](https://console.anthropic.com/settings/keys) и хранится только
в браузере игрока. Без ключа работает всё, кроме свободных разговоров.

> Ключ отправляется из браузера напрямую в API Anthropic. Это нормально для личной игры,
> но если выкладываете игру публично для других людей — не встраивайте свой ключ в сборку.

### Графика

**Телефон → Настройки → Графика**: «Высокое» (все эффекты), «Среднее» (для телефонов,
выбирается автоматически) и «Низкое» (без пост-обработки, для слабых устройств).

## Управление

- **ПК:** WASD / стрелки — ходить, **E** — говорить/действовать, **P** — телефон, колёсико — зум
- **Телефон:** тап по земле — идти, тап по персонажу — подойти и заговорить

## Как расширять игру

Смотри [HOW_TO_EXTEND.md](HOW_TO_EXTEND.md): как добавить главу, персонажа, район,
предмет мебели, фразы прохожих или новый тип упражнения. Идея и план развития —
в [docs/GDD.md](docs/GDD.md).

## Технологии

Vite · Three.js · postprocessing + N8AO (шейдерные эффекты) · Web Speech API ·
Anthropic SDK (Claude Haiku 5.5). Без бэкенда: прогресс хранится в браузере.
