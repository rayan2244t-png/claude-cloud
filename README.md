# 🍎 Big Apple — американский английский в Нью-Йорке

Уютная 3D-игра для изучения **американского английского** с нуля (A1 → A2).
Ты прилетаешь в Нью-Йорк, почти не зная языка, и строишь жизнь: снимаешь комнату,
заказываешь кофе, находишь работу и друзей. Каждый разговор — урок, а ошибки
игра объясняет по-русски.

Графика — low-poly в стиле Untitled Goose Game с «шейдерпаком», как в Minecraft:
мягкие тени (ambient occlusion), тени облаков, лучи солнца, свечение огней ночью,
мокрый асфальт в дождь, качающаяся листва и эффект миниатюры (tilt-shift).

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173 (откроется и с телефона в той же Wi-Fi сети)
npm run build      # готовая сборка в папке dist/ — её можно выложить на любой хостинг
```

Голос (микрофон) лучше всего работает в Chrome. Озвучка — встроенная в браузер (американский голос).

### ИИ-разговоры

**Телефон → Настройки → ИИ-собеседники**:
- **Claude Haiku 5.5** — лучшее качество, нужен API-ключ с [console.anthropic.com](https://console.anthropic.com/settings/keys).
- **Локальная модель (Ollama)** — бесплатно, без интернета, работает там, где Claude недоступен. Нужен компьютер с 8+ ГБ памяти:
  ```bash
  # 1. Установить Ollama: https://ollama.com/download
  ollama pull qwen2.5:7b
  # 2. Разрешить доступ из браузера и запустить
  OLLAMA_ORIGINS=* ollama serve
  ```
  Windows: `setx OLLAMA_ORIGINS *`, затем перезапустить Ollama.

> Ключ Claude отправляется из браузера напрямую в API Anthropic. Для личной игры это нормально; не встраивайте свой ключ в публичную сборку.

### Графика

**Телефон → Настройки → Графика**: «Высокое», «Среднее», «Низкое». Если игра тормозит, она сама предложит снизить качество.

## Как поиграть по ссылке и на телефоне

1. **GitHub Pages:** в репозитории — Settings → Pages → Source: **GitHub Actions**. Влейте ветку в `main` — игра соберётся и опубликуется автоматически (`.github/workflows/deploy.yml`).
2. **Иконка на рабочем столе:** на стартовом экране (или Телефон → Настройки) нажмите **«📲 Иконка на рабочий стол»**. Игра установится как приложение с иконкой 🍎 (ПК — Chrome/Edge, Android — Chrome, iPhone — Safari → «Поделиться» → «На экран „Домой“») и будет работать офлайн (кроме ИИ).
   Без публикации на ПК: папка [`launcher/`](launcher/README.md) — ярлык Windows (`Создать ярлык на рабочем столе.ps1`) и запуск для macOS/Linux.
3. **Перенос прогресса:** Телефон → Настройки → «Скопировать код сохранения» на одном устройстве и «Загрузить сохранение» на другом.

## Управление

- **ПК:** WASD / стрелки — ходить, **E** — говорить/действовать, **P** — телефон, **L** — учебник, колёсико — зум
- **Телефон:** тап по земле — идти, тап по персонажу — подойти и заговорить

## Как расширять игру

Смотри [HOW_TO_EXTEND.md](HOW_TO_EXTEND.md): как добавить главу, персонажа, район,
предмет мебели, фразы прохожих или новый тип упражнения. Идея и план развития —

## Технологии

Vite · Three.js · postprocessing + N8AO (шейдерные эффекты) · Web Speech API ·
Anthropic SDK (Claude Haiku 5.5). Без бэкенда: прогресс хранится в браузере.
