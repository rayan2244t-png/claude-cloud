# Ярлык Big Apple на рабочем столе

Есть два способа получить иконку 🍎.

## Способ 1. Установить как приложение (лучший)

Открой игру в Chrome/Edge (по ссылке GitHub Pages или через ярлык из способа 2) →
на стартовом экране нажми **«📲 Иконка на рабочий стол»** (или Телефон → Настройки).
Браузер установит игру: появится иконка на рабочем столе и в меню «Пуск»,
игра будет открываться в своём окне и работать без интернета.

На телефоне: Android — Chrome → ⋮ → «Установить приложение»;
iPhone — Safari → «Поделиться» → «На экран „Домой“».

## Способ 2. Запуск с компьютера без публикации

Нужен [Node.js](https://nodejs.org) (LTS).

**Windows**
1. Правой кнопкой по `Создать ярлык на рабочем столе.ps1` → «Выполнить с помощью PowerShell».
2. На рабочем столе появится ярлык **Big Apple** с яблоком. Двойной клик — игра откроется
   в отдельном окне (первый запуск дольше: ставятся зависимости и собирается игра).

Если PowerShell ругается на политику запуска, можно просто создать ярлык вручную:
правой кнопкой по `Big Apple.bat` → «Отправить» → «Рабочий стол (создать ярлык)»,
затем в свойствах ярлыка → «Сменить значок» → `public\favicon.ico`.

**macOS / Linux**: двойной клик по `Big Apple.command`
(на macOS первый раз: правой кнопкой → «Открыть»). Чтобы поставить яблоко на иконку,
перетащи `public/icons/icon-512.png` в окно «Свойства» файла (⌘I) на значок.

> После изменений в коде игры удали папку `dist`, чтобы ярлык пересобрал игру.
