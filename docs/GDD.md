# Big Apple — дизайн-документ

## Идея
Игра, а не курс. Игрок — новичок в Нью-Йорке, почти без английского. Язык нужен,
чтобы жить: снять жильё, поесть, найти работу и друзей. Каждый диалог — квест и урок
одновременно. Ошибки не наказываются, а объясняются (по-русски) и потом повторяются.

**Фокус — американский английский:** сленг (awesome, gonna, buddy, I'm down),
американские слова (subway, sidewalk, trash can, to go), реалии (чаевые, a.m./p.m.,
bucks, бодеги, дайнеры) и американская озвучка.

## Основной цикл
1. Гуляешь по живому городу (прохожие, машины, голуби, смена дня и ночи, погода).
2. Говоришь с людьми → диалог-урок с упражнениями.
3. Получаешь опыт, деньги, слова, новые места.
4. Повторяешь: словарь с интервалами, дневник ошибок, задание дня.

## Обучение
- **Уровни:** A1.1 → A1.2 → A1.3 → A2.1 → A2.2 → B1 (по опыту).
- **Главы = этапы жизни:** 1 «Бруклин» (выжить, A1), 2 «Манхэттен» (устроиться, A2).
- **Упражнения:** выбор, сборка фразы, письмо, голос, аудирование.
- **Ошибки:** объяснение + правильный вариант + запись в дневник + слабые темы.
- **Погружение:** подслушанные фразы прохожих, подписи предметов, сленг-яблоки,
  шпаргалка, переписка в телефоне, свободный разговор с ИИ (Claude Haiku 5.5).

## Визуальный стиль
Low-poly «игрушечный» город в пастельных тонах (как Untitled Goose Game) + шейдерпак:
SSAO, тени облаков, god rays на рассвете и закате, bloom ночью, мокрый асфальт,
качающаяся листва, tilt-shift. Три уровня качества.

## План развития
- **Глава 3 «Queens / JFK» (A2):** аэропорт, банк, врач, звонок по телефону.
- **Глава 4 «Coney Island» (A2+):** пляж, парк аттракционов, планы на будущее (will / going to).
- **Глава 5 «Central Park» (B1):** свидание, споры, Present Perfect.
- Мини-игры: смена в дайнере, такси-навигатор, караоке.
- Ежедневные события в городе (парад, фермерский рынок, снег зимой).
- Голосовые разговоры с ИИ (речь → текст → Claude → озвучка).
- Достижения и косметика для героя.
